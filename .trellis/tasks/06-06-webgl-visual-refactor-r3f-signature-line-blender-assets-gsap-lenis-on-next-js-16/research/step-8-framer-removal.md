## 2. GSAP approach with code sketches (for INSTALLED gsap 3.15.0)

### (a) `reveal-on-scroll.tsx` → GSAP (mirror `ui/reveal.tsx`, do NOT reuse it)

**Decision: small PARALLEL impl inside `reveal-on-scroll.tsx`.** Reason — least duplication that is still SAFE: the mechanism (IO + `gsap.set` initial / `gsap.to` `expo.out` / played-once / RM-static) is mirrored, but two contracts differ and forbid sharing the exact `Reveal` component:
- **Units**: RevealOnScroll `delay` is SECONDS; `ui/reveal.tsx` is MS (`delay/1000`). Reusing `Reveal` directly would require the consumers to change units → that breaks "consumers untouched".
- **API surface**: RevealOnScroll exposes `y` / `duration` / `as` (incl. `"section"`/`"article"`) + a configurable `y` magnitude; `Reveal` exposes `variant` / `from` and a fixed `0.85`/`expo.out` tween. Different prop shapes.

The framer `amount: 0.3` (30% of the element visible) maps to an IntersectionObserver `threshold: 0.3`. Keep `ui/reveal.tsx`'s `rootMargin: "0px 0px -18% 0px"` too if you want the identical "fires slightly before fully crossing" feel — but the faithful map of framer's `amount:0.3` is `threshold: 0.3` with `rootMargin: "0px"`. **OPEN DECISION (D2)** below picks one; default recommendation: `threshold: 0.3, rootMargin: "0px"` (exact framer semantics — element appears when 30% visible).

```tsx
"use client";

import { createElement, useEffect, useRef, type ReactNode } from "react";
import gsap from "gsap";

interface RevealOnScrollProps {
  children: ReactNode;
  delay?: number;      // SECONDS (matches old framer transition.delay)
  y?: number;
  duration?: number;   // SECONDS
  as?: "div" | "section" | "article";
  className?: string;
}

export function RevealOnScroll({
  children,
  delay = 0,
  y = 24,
  duration = 0.6,
  as = "div",
  className,
}: RevealOnScrollProps) {
  const ref = useRef<HTMLElement | null>(null);
  const playedRef = useRef(false);

  useEffect(() => {
    const el = ref.current;
    if (!el || playedRef.current) return;

    const prefersReduced =
      typeof window !== "undefined" &&
      window.matchMedia("(prefers-reduced-motion: reduce)").matches;

    if (prefersReduced) {
      // RM-static: framer returned the plain element (no transform). Mirror that.
      gsap.set(el, { opacity: 1, y: 0 });
      playedRef.current = true;
      return;
    }

    gsap.set(el, { opacity: 0, y });

    const play = () => {
      if (playedRef.current) return;
      playedRef.current = true;
      gsap.to(el, {
        opacity: 1,
        y: 0,
        duration,                 // seconds — same as framer
        delay,                    // seconds — DO NOT divide by 1000
        ease: "expo.out",         // mirrors EASE cubic-bezier(0.16,1,0.3,1)
      });
    };

    // amount:0.3 (framer) -> IO threshold:0.3. once:true -> disconnect after play.
    // IO fires at observe time when already-in-view (covers SPA nav mount-in-view),
    // exactly like ui/reveal.tsx — the documented reason to use IO over ScrollTrigger.
    const io = new IntersectionObserver(
      (entries) => {
        for (const entry of entries) {
          if (entry.isIntersecting) {
            play();
            io.disconnect();
            break;
          }
        }
      },
      { threshold: 0.3 },
    );
    io.observe(el);

    return () => io.disconnect();
  }, [delay, y, duration]);

  return createElement(
    as,
    { ref, className } as Record<string, unknown>,
    children,
  );
}

export default RevealOnScroll;
```

Notes:
- `createElement(as, { ref, ... })` keeps the `as` union working with a single typed ref; `useRef<HTMLElement | null>` covers div/section/article. (Same `@ts-expect-error`-style tag-union trick `ui/reveal.tsx` uses; here `createElement` avoids needing the directive.)
- Initial paint: `gsap.set(opacity:0)` runs in `useEffect` (client). To avoid a one-frame flash of fully-opaque content before the effect runs, consider a CSS `will-change`/initial inline `style={{opacity:0}}` ONLY if QA shows a flash — but framer also set initial on mount via JS, so behavior is equivalent; do NOT add SSR `opacity:0` that could hide content if JS fails (a11y/no-JS). Keep parity with framer (JS-set initial). Flag for QA.
- **No consumer relies on framer-specific behavior** (verified: only `delay` + `className` passed; `whileInView once` → IO `once` semantics replicated; no layout/exit/AnimatePresence on RevealOnScroll). Safe.

### (b) `navbar.tsx` dropdown → GSAP (EaseReverseClipMenu style)

**Core pattern (codrops EaseReverseClipMenu / J0SUKE):** one GSAP timeline built once, played forward on open and `reverse()`d on close. Reverse is inherently INTERRUPTIBLE — calling `reverse()` mid-`play()` (or vice-versa) picks up from the live playhead, no kill/rebuild needed. The "distinct snappier close" (the *easeReverse* feel) is achieved by **boosting `timeScale` on the reverse leg** and/or building the close as a separate faster ease — both are valid; `timeScale` is the canonical codrops approach and avoids a second timeline.

**Mount strategy:** keep the panel ALWAYS MOUNTED (drop `AnimatePresence`); drive visibility purely via the timeline (start state = hidden via `gsap.set` at timeline position 0). This removes the unmount-race entirely and is simplest with `useGSAP`. (Alternative: `isVisible` state unmounted on close `onReverseComplete` — more code, only needed if keeping it mounted hurts a11y/tab-order; see §3 + D3.)

**AVOID `height: "auto"`** (GSAP cannot tween to `auto`). Use **`clipPath` inset from origin-top** (the "tenda"/curtain unroll, equivalent to the old framer `height 0→auto` with `origin-top`). `scaleY` from `transformOrigin: top` is the alternative but distorts the pill text during the tween; **`clip-path: inset(0 0 X% 0)` is preferred** (no distortion, matches the curtain language already in `template.tsx`).

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import gsap from "gsap";
import { useGSAP } from "@gsap/react";
import { CustomEase } from "gsap/CustomEase";   // available in 3.15.0 — see §0
// ...existing imports MINUS framer-motion...

gsap.registerPlugin(useGSAP, CustomEase);
// One-time easeReverse: a snappier "in" curve, distinct from the open's expo.out.
// (If you prefer zero plugin surface, skip CustomEase and use "power3.in" — see D1.)
const EASE_OPEN = "expo.out";
const CLOSE_EASE = CustomEase.create("easeReverse", "0.7,0,0.84,0"); // ~power3.in, snappy

export function Navbar() {
  const pathname = usePathname();
  const { language } = useLanguage();
  const [open, setOpen] = useState(false);
  const [scrolled, setScrolled] = useState(false);
  const triggerRef = useRef<HTMLButtonElement>(null);
  const panelRef = useRef<HTMLDivElement>(null);
  const listRef = useRef<HTMLUListElement>(null);
  const tlRef = useRef<gsap.core.Timeline | null>(null);

  // reduced-motion read (replaces framer useReducedMotion) — read once, client.
  const reduceRef = useRef(false);
  useEffect(() => {
    reduceRef.current =
      typeof window !== "undefined" &&
      window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  }, []);

  // ---- ALL EXISTING PLAIN-REACT LOGIC PRESERVED VERBATIM ----
  // route-change close:
  useEffect(() => { setOpen(false); }, [pathname]);
  // scrolled border via scrollStore subscribe (NOT a private window listener):
  useEffect(() => {
    const update = () => setScrolled(window.scrollY > 24);
    update();
    return useScrollStore.subscribe(update);
  }, []);
  // open-effect: getLenis().stop() + body overflow hidden + Esc + outside
  // pointerdown + focus-return to triggerRef — UNCHANGED from current code.
  useEffect(() => {
    if (!open) return;
    getLenis()?.stop();
    const prevOverflow = document.body.style.overflow;
    document.body.style.overflow = "hidden";
    const onKeyDown = (e: KeyboardEvent) => {
      if (e.key === "Escape") { setOpen(false); triggerRef.current?.focus(); }
    };
    const onPointerDown = (e: PointerEvent) => {
      const t = e.target as Node | null;
      if (!t) return;
      if (triggerRef.current?.contains(t) || panelRef.current?.contains(t)) return;
      setOpen(false);
    };
    document.addEventListener("keydown", onKeyDown);
    document.addEventListener("pointerdown", onPointerDown);
    return () => {
      document.removeEventListener("keydown", onKeyDown);
      document.removeEventListener("pointerdown", onPointerDown);
      document.body.style.overflow = prevOverflow;
      getLenis()?.start();
    };
  }, [open]);

  // ---- NEW: build the timeline ONCE (paused), then play/reverse on `open` ----
  useGSAP(
    () => {
      const panel = panelRef.current;
      if (!panel) return;
      const items = listRef.current
        ? gsap.utils.toArray<HTMLElement>(listRef.current.children)
        : [];

      if (reduceRef.current) {
        // RM branch: plain fade only, NO clip-path unroll, NO stagger.
        const tl = gsap.timeline({ paused: true });
        gsap.set(panel, { autoAlpha: 0 });
        tl.to(panel, { autoAlpha: 1, duration: 0.2 });
        tlRef.current = tl;
        return;
      }

      // Full motion: clip-path curtain unroll (origin-top) + opacity + staggered pills.
      gsap.set(panel, { autoAlpha: 0, clipPath: "inset(0 0 100% 0)" }); // collapsed at top
      gsap.set(items, { autoAlpha: 0, y: 8 });

      const tl = gsap.timeline({
        paused: true,
        defaults: { ease: EASE_OPEN },
        // distinct close: boost reverse speed -> "easeReverse" snap.
        // (Alternatively set CLOSE_EASE per-tween; timeScale is the codrops way.)
      });
      tl.to(panel, { autoAlpha: 1, clipPath: "inset(0 0 0% 0)", duration: 0.4 }, 0)
        .to(items, { autoAlpha: 1, y: 0, duration: 0.35, stagger: 0.04 }, 0.08);
      tlRef.current = tl;
    },
    { scope: panelRef, dependencies: [] },
  );

  // Drive the timeline off `open`. Interruptible: reverse()/play() pick up live.
  useGSAP(
    () => {
      const tl = tlRef.current;
      if (!tl) return;
      if (open) {
        tl.timeScale(1).play();
      } else {
        // Close: snappier. timeScale>1 makes the reverse leg faster (easeReverse feel).
        tl.timeScale(reduceRef.current ? 1 : 1.6).reverse();
      }
    },
    { dependencies: [open], scope: panelRef },
  );
  // ...isActive / listVariants&itemVariants REMOVED (now timeline) / render...
}
```

**Render changes** (in the JSX): drop `<AnimatePresence>` and `motion.*`. The panel becomes a plain `<div ref={panelRef} id="site-menu" ...>` that is ALWAYS rendered (no `{open && ...}` gate — visibility is the timeline's `autoAlpha`). The `<ul>` gets `ref={listRef}` and its `<li>`s are plain `<li>` (stagger targets the children). Keep the exact `className`, inline `style`, the `origin-top`, the `MenuPill` children, and the `lg:hidden` footer cluster unchanged. The Menu⟷X icon morph is pure Tailwind (`open` toggles classes) and is UNTOUCHED.

**Why interruptible without kill/rebuild:** a single paused timeline + `play()`/`reverse()` is the GSAP-idiomatic interruptible toggle. Reversing mid-open resumes from the current progress; no `gsap.from` + `invalidate().restart()` anti-pattern (explicitly forbidden by the frontend GSAP-traps spec). Because the panel is always mounted, there is NO unmount to defer.

**aria/focus preserved:** `aria-expanded={open}`, `aria-haspopup="true"`, `aria-controls="site-menu"`, the bilingual `aria-label`, and focus-return (`triggerRef.current?.focus()` on Esc) all stay. NOTE (a11y, see §5/D3): an always-mounted panel is in the tab order even when visually closed. Mitigate with `aria-hidden={!open}` + `inert` (or `pointer-events:none` + `tabIndex:-1` on the links via `autoAlpha:0`, which `gsap` sets `visibility:hidden` → removes from tab order automatically). `autoAlpha` (opacity+visibility) is the clean win here: `visibility:hidden` takes the panel out of the a11y/tab tree for free, matching framer's unmount behavior.
