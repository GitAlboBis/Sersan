## Package 1 — Cinematic camera (OWNER: main session, inline)

Files: src/webgl/SignatureLine.tsx, NEW src/webgl/store/cameraRigStore.ts, src/webgl/HeroLogo.tsx,
src/webgl/HeroTextParticles.tsx, src/webgl/store/fxStore.ts (knobs).

1. **Breathing dolly-Z (velocity-linked)**: dzTarget = smooth clamp of |velNorm| → camera pulls back up to
   DOLLY_MAX ≈ 1.15 world units while travelling, settles to 0 at rest (snap engine guarantees rests at stations).
   Damped λ ≈ 2.2 (slower out than in is fine). Registration safe: at rest dz=0 → exact DOM registration.
2. **Arrival micro-orbit**: proximity to the active ritual anchor (RouteHero/GatewayPortal world-Y) drives a small
   camera.position.x offset (≤ 0.38 world) shaped sin(arrival·π), damped — orbital parallax around world-anchored
   rituals. lookAt unchanged (curve target) so it reads as a vantage drift, not a pan.
3. **Mouse micro-parallax on camera**: damped pointerStore offset (±0.06 world x, ±0.04 y, λ=3). GATES: tier full,
   fine pointer, NOT during intro (textMorphStore.active/assemble phase), NOT while scrollPx <= 2, reduced-motion off.
4. **cameraRigStore** (plain module, not React): { dollyZ, orbitX, parX, parY } written once per frame by
   SignatureLine BEFORE billboards read camera. HeroLogo + HeroTextParticles subtract parX/parY (and NOT dollyZ —
   z-depth response is the desired depth cue) so mouse motion produces true parallax against them instead of
   being cancelled. RouteHero: no change (world-anchored = free parallax).
5. Leva-style dev knobs via fxStore (dollyMax, orbitAmp, parAmp) + window.__sersanFx for live tuning.
